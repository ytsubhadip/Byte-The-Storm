# BYTE THE STORM — Frontend

HTML/CSS/JavaScript frontend prototype for the SIH cyclone intelligence project.

## Structure
- index.html — Dashboard
- pages/ — Live Map, Forecast, Alerts, Data Sources, About
- css/ — shared styling
- js/ — map, dashboard and page scripts
- assets/ — images/icons

## Run
Open `index.html` in a browser, or use VS Code Live Server.

The current values are demo data. Replace them later with FastAPI API responses.
