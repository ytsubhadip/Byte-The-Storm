# CSS structure

- `style.css` — global/base styles
- `navbar.css` — top navigation and branding
- `dashboard.css` — dashboard cards, analysis and charts
- `map.css` — Leaflet/map layout and map controls
- `forecast.css` — forecast page styles
- `alerts.css` — alert page styles
- `satellite.css` — satellite/data source page styles
- `about.css` — About/How It Works styles
- `responsive.css` — tablet/mobile responsive rules

Each HTML page loads the global files plus only the CSS it needs.
